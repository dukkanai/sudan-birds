# سوق الطيور السوداني

مشروع Flutter مستقل في مستودع عام لتطبيق iOS وAndroid باللغة العربية. الواجهة تحتوي تبويبين فقط: **طلبات، معروضات**. التطبيق مجاني للمستخدمين ولا يحتوي دفعًا أو عمولات أو اشتراكات أو إعجابات أو متابعة.

**الحالة: نسخة تطوير قيد المراجعة والربط التجريبي، وليست إصدارًا جاهزًا للاستخدام العام.** لم يُنشر تطبيق متجر أو خادم إنتاج. عند غياب إعدادات Supabase تظهر الواجهة وضع المعاينة بوضوح ولا تدّعي حفظ بيانات.

## التشغيل

- Flutter **3.38.5**، Dart المرفق معه. التبعيات مقفلة في `app/pubspec.lock`.
- من `app/`: `flutter pub get` ثم `flutter run` للمعاينة المحلية.
- للبيئة المتصلة: استخدم `--dart-define=SUPABASE_URL=...` و`--dart-define=SUPABASE_ANON_KEY=...` و`--dart-define=AUTH_REDIRECT_URL=...` بعد تجهيز مشروع اختبار وتطبيق الترحيلات. المفتاح القابل للنشر عام، لكن **service_role وأسرار R2 ممنوعة في التطبيق**.
- تعليمات قاعدة البيانات في `supabase/README.md`، وتفاصيل التحقق في `docs/verification.md`.

## البنية

- `app/`: واجهة عربية RTL، نموذج بيانات، تحقق إدخال، حدود أخطاء، واختبارات.
- `supabase/`: ترحيلات PostgreSQL، صلاحيات RLS، اختبارات سلبية، ووظائف خادم.
- `docs/`: المتطلبات والهندسة والخصوصية وبوابات الإصدار.
- `.github/workflows/`: فحوص دون أسرار على طلبات الدمج. مسارات التوزيع مغلقة حتى استكمال الاعتماد والتوقيع.

حاوية صور تجريبية خاصة موجودة باسم `sudan-birds-media-staging` (R2 Standard). لا يوجد وصول عام إليها أو مفاتيح في المستودع. إنشاء الحاوية لا يعني أن رفع الصور أو ربط التطبيق أصبح جاهزًا.

## التحقق

```sh
cd app
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

راجع `docs/verification.md` لمعرفة ما نُفذ فعلًا وما لم يُنفذ. لا تكفي اختبارات الواجهة لإثبات أمان الخادم، ولا تغني عن VoiceOver وTalkBack على أجهزة حقيقية.

## قبل التجربة الحقيقية

مشروع Supabase المخصص للتجربة موجود وقد طُبّقت عليه الترحيلات الثلاث، بما فيها إزالة جداول الاستشارات والردود والمواضيع بعد الموافقة المحددة. نجح بعدها 23 فحصًا مباشرًا للمخطط والصلاحيات و12 فحص API للقراءة فقط. نُشرت وظائف الخادم الخمس على نسخة اجتازت الفحوص السبعة، وطُبّق تعديل التحقق الموافق عليه مع إبقاء التحقق من هوية المستخدم داخل الوظائف المحمية وسياسات قاعدة البيانات. نجح 29 فحصًا مباشرًا لرفض الوصول غير المصرّح به والقراءة العامة.

نجح أيضًا اختبار معالجة الصورة الاصطناعية على Supabase: رُفض طلب بلا رمز، ونجحت 19 معالجة من أصل 19. حُذفت وظيفة الاختبار ورمزها وتحقق الحذف خلال نحو ثلاث دقائق. هذا الاختبار المحدود لا يثبت جاهزية رفع الصور أو ربط R2.

يلزم إكمال اختبار جلسات المستخدمين الحقيقية، وتهيئة مزودي Google وApple، وقناة آمنة لأسرار الخادم، واختبار الرفع والحذف الكامل على R2 فعليًا، واعتماد الخصوصية والدعم، واختبارات أجهزة واتصال ضعيف. وظائف الصور والحذف والإشراف موجودة في الشيفرة، لكن نجاح الاختبارات المحلية لا يثبت عملها المتكامل في البيئة المستضافة. رفع الصور معطّل افتراضيًا حتى اجتياز اختبارات الموارد والأمان. لا ترفع بيانات حقيقية قبل استكمال هذه البوابات.

لا يوجد نشر تلقائي عند التغيير على `main`. لا تُدمج هذه البداية أو تُنشر قبل مراجعة نتائج الفحوص لنفس SHA. راجع `SECURITY.md` و`docs/release-runbook.md`.


المستودع عام، لكن لم تُحدد رخصة إعادة استخدام للشيفرة بعد. ظهور المصدر للعامة لا يمنح تلقائيًا رخصة مفتوحة المصدر.
