# Temporary synthetic-only staging diagnostic

This is not a user-image endpoint. It has no Auth helper, service key, R2 client, database
operation, upload handling or user data. It accepts only POST with no body and no query. Its only
input image is the committed inline synthetic640×640 noise fixture. Each real request performs at
most one bounded sanitize and returns only elapsed time, dimensions, byte counts and memory metrics.

Deployment operator procedure, not performed by this source:

1. Commit/review the source. Resolve the exact immutable Git SHA.
2. Create a temporary staging function with JWT verification enabled.
3. Its entry imports createCodecDiagnostic from the immutable raw GitHub URL ending
   `/supabase/functions/codec-diagnostic/handler.ts` and calls
   `Deno.serve(createCodecDiagnostic("FIXED_UTC_DEADLINE", Deno.env.get("CODEC_DIAGNOSTIC_TOKEN")))`.
4. Replace that placeholder with a literal UTC deadline no more than20minutes from deployment. NEVER
   use Date.now()+20minutes in the wrapper: each new isolate would otherwise extend the lifetime.
   Committed index.ts deliberately has an invalid deadline and returns410 until an explicit operator
   test.
5. Make at most20total empty POST requests, including any bounded burst, with normal
   event-loop/network turns between sequential requests. Each isolate accepts at most20calls. Record
   responses, deployment/runtime identity, cold/warm timings and heap/external/RSS separately. Do
   not send any arbitrary image, token in the request body, or user content.
6. Do not infer actual media throughput from this codec-only bundle: actual media also imports
   AWS/Supabase clients. The main upload flag staysfalse after this probe until full media
   integration and resource tests pass. Remove the temporary function and approved temporary
   credential when finished; hard expiry is a backstop, not a substitute for that cleanup. No
   scheduler is created here.

fixture.ts is generated from seeded pseudorandom RGB pixels and contains no EXIF or personal data.
The inline source is below1MiB, avoiding bundle asset fetching and import.meta.url differences.
Local tests cover hard-expiry and rejection of input.

## Required temporary caller approval

The handler requires x-codec-diagnostic-token matching an explicitly supplied 43-character base64url
secret, compared via fixed32-byte hashes with no early exit. Unset or wrong credentials fail before
fixture decoding/codec work. The wrapper may read ONLY the approved CODEC_DIAGNOSTIC_TOKEN and pass
it as the second argument; the module itself reads no environment. No token was generated by this
code. Creating the temporary credential requires action-time approval. Send it only in the header,
never query/body/logs or committed entry. Remove it after the bounded test. The20-call limit is
per-isolate, not a global budget; the operator should issue at most 20total synthetic requests
during the fixed20-minute window and then disable the probe.
